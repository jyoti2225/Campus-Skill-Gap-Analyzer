# Campus Skill Gap Analyzer

A Java-based application that compares student skills with job-profile requirements and identifies skill gaps.

## Project Overview

Campus Skill Gap Analyzer is a Java desktop application designed to help students understand which technical skills they have and which skills they need to improve for different job profiles.

The application compares a student's skills with the required skills for selected job profiles and identifies missing skills.

## Problem Statement

Students often have difficulty understanding which technical skills are required for different job roles.

This project provides a simple way to compare student skills with job-profile requirements and identify areas where additional learning is needed.

## Features

- Add and manage student skills
- Compare skills with different job profiles
- Identify missing skills
- Analyze job-profile requirements
- Store data using MySQL
- Connect Java application with MySQL using JDBC
- Use SQL queries for skill and job-profile analysis

## Technologies Used

- Java
- MySQL
- JDBC
- SQL
- Git
- GitHub

## How It Works

1. The student provides their technical skills.
2. The application compares these skills with the required skills of a job profile.
3. The system identifies matching skills.
4. Missing skills are identified as skill gaps.
5. The results help the student understand which skills they can improve.
